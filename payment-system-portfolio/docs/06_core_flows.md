# 핵심 흐름 (Core Flows)

## 결제 승인 흐름

1. 가맹점이 승인 요청 전송
2. Idempotency Key 검증
3. Payment 생성 (PENDING)
4. 외부 결제 시스템 승인 요청
5. 승인 결과 수신
6. 상태 전이 (APPROVED / FAILED)
7. 이벤트 로그 기록

---

## 결제 취소 흐름

1. 원거래 조회
2. 취소 가능 상태 검증
3. 외부 결제 시스템 취소 요청
4. 결과에 따라 상태 전이
5. 취소 이력 기록

---

## 조회 흐름
- 승인/취소 로직과 완전히 분리된 읽기 전용 흐름
- 운영자/가맹점 모두 동일한 원장 기준 조회
